# tele_claude

Один Telegram-бот, а у каждой сессии Claude Code своя тема (forum topic) в группе.
Пишете в тему — сообщение попадает только в эту сессию, ответ возвращается в ту же тему.
Работает на macOS. Токен знает только локальный демон (router), сессии его не видят.

## Что умеет
- Тема на каждую сессию; сообщения из темы идут только своей сессии.
- Главная сессия общается в общей теме General (`--main`).
- Живая строка статуса: что сейчас делает сессия (читает файл, запускает команду, думает…), анимация «печатает…».
- `/stop` или кнопка «⛔ Прервать» — как Esc в терминале.
- `/windows`, `/show`, `/hide`, `/hideall` — открыть/скрыть окно терминала с сессией кнопками (сессии живут в tmux).
- `/screen` — скриншот вкладки Chrome сессии и кнопки управления (нужно расширение Claude in Chrome).
- Файлы, фото, реакции, запросы разрешений кнопками — как в официальном плагине Telegram.

## Установка
Нужны: macOS, [bun](https://bun.sh), tmux, Claude Code.

1. Создайте бота у @BotFather, возьмите токен. В BotFather → Bot Settings включите *Allow Groups*.
2. Создайте группу, включите в ней «Темы» (она станет форумом), добавьте бота администратором с правами
   «Управление темами» и «Удаление сообщений».
3. Узнайте id группы (число вида `-100…`; например, перешлите сообщение из группы боту @getidsbot) и свой Telegram user id.
4. Настройка:
   ```sh
   git clone <этот репозиторий> && cd tele_claude && bun install
   mkdir -p ~/.tele_claude && chmod 700 ~/.tele_claude
   cp config.example.json ~/.tele_claude/config.json     # впишите chat_id и свой user id в allow_from
   echo 'TELEGRAM_BOT_TOKEN=123456:ABC...' > ~/.tele_claude/.env && chmod 600 ~/.tele_claude/.env
   claude mcp add --scope user tele -- bun "$PWD/client/server.ts"
   ./launchd/install.sh      # необязательно: автозапуск роутера
   ```
5. Запуск сессии: `bin/tele-claude <каталог> [--name <название>] [--resume <id>] [--main]`
   (при первом запуске подтвердите вопрос про dev-канал: пункт 1). Положите `bin/` в PATH для удобства.
6. Перенести уже запущенные сессии (контекст сохранится через `--resume`): `bin/tele-claude-all` показывает план,
   `bin/tele-claude-all --go` выполняет. Внимание: старые сессии при этом останавливаются.

Файл `~/.tele_claude/config.json`: `chat_id` (группа), `allow_from` (кому можно писать боту), необязательно `token_file`
(другой файл с токеном). Чужим бот не отвечает.

## Устройство
- `router/router.ts` — демон, единственный держатель токена (long polling), раздаёт сообщения по темам. Один экземпляр (замок).
- `client/server.ts` — MCP-канал для сессии (reply, react, edit_message, download_attachment), говорит с роутером по unix-сокету.
- `bin/tele-claude`, `bin/tele-claude-all` — запуск сессий.
- Состояние: `~/.tele_claude/` (sessions.json — какая сессия в какой теме, router.sock, inbox/, router.log).
- Тесты: `bun test` (поддельный Telegram, настоящего бота не трогают).

## Ограничения
- У бота один читатель обновлений: пока работает роутер, официальный плагин telegram на том же токене работать не будет.
- Claude Code не отдаёт текст рассуждений наружу: показываются действия, а рассуждения — только если они есть в журнале сессии.
- Файлы больше 50 МБ пока не отправляются.
